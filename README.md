# 資材管理システム

PythonとStreamlitで作成した、Web版の資材管理システムです。

資材の入出庫や在庫確認、発注、棚卸などの作業をWebブラウザ上で行えます。
各種データはGoogleスプレッドシートへ保存されます。

## 主な機能

* 商品登録・更新・削除
* 資材の入庫・出庫
* 在庫数および不足在庫の確認
* 使用会社・形区分による在庫検索
* 入出庫履歴の確認
* 発注情報の登録・変更・取消
* 分納および納入状況の管理
* 入出庫履歴の取消
* 在庫数の修正
* 棚卸モードの切替
* 棚卸結果および差異の確認
* 在庫一覧と同期した現品票・棚札の作成
* 在庫帳簿のExcel出力
* 発注書のExcel出力
* ログインユーザーと操作履歴の管理

## ログイン権限

ログインユーザーの役割に応じて、利用できる機能を制限しています。

* **一般**：入出庫、在庫確認、履歴確認
* **発注担当**：一般ユーザーの機能、発注、発注情報の変更・取消
* **管理者**：すべての機能、商品管理、在庫修正、棚卸モードの管理

## 棚卸機能

棚卸モードをONにすると、一般ユーザーによる入出庫を停止できます。

棚卸時に入力した実際の在庫数と、システム上の在庫数を比較し、棚卸状況を次のように記録します。

* 在庫数が一致：`済`
* 在庫数に差異あり：`要確認`
* 棚卸未実施：`未`

管理者は棚卸結果を確認し、棚卸終了後に棚卸情報をリセットできます。

## 現品票・棚札

Googleスプレッドシート上に、在庫一覧と同期した現品票および棚札を作成しています。

* **現品票**：棚卸時の在庫確認および実棚数の記入に使用
* **棚札**：保管場所で資材コード、品名、型式・寸法などを確認するために使用

在庫一覧の情報を利用することで、商品情報を個別に転記する手間や入力間違いを減らせます。

## データの保存

以下のデータをGoogleスプレッドシートで管理しています。

* 商品および在庫情報
* 入出庫履歴
* 発注履歴
* 棚卸結果
* 棚卸モードの状態
* 在庫一覧と同期した現品票・棚札

## 実行方法

必要なライブラリをインストールします。

```bash
pip install -r requirements.txt
```

Streamlitでアプリを起動します。

```bash
streamlit run 資材管理システム_web.py
```

Googleスプレッドシートとの接続情報やログイン情報は、StreamlitのSecretsで設定する必要があります。
